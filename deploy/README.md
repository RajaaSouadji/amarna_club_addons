# Amarna Club on Docker (server 10.20.10.49)

Odoo 20 and PostgreSQL 16 run as two containers (`amarna-odoo-1`, `amarna-db-1`).
The addons are this repository, cloned in `/opt/amarna/addons` and mounted read-only
in the Odoo container. Compose project: `/opt/amarna/addons/deploy`.

| What | Where |
|---|---|
| Web + JSON-RPC (tablet) | `http://10.20.10.49:8069`, database `hasnaoui_amarna` |
| Database | PostgreSQL container, volume `amarna_amarna_pg` (not published on the network) |
| Filestore, sessions | volume `amarna_amarna_odoo` (`/var/lib/odoo` in the container) |
| Secrets | `deploy/.env` and `deploy/odoo.conf` (generated by `setup.sh`, not in git) |
| Backups | `/opt/amarna/backups`, every night 02:30, kept 14 days (cron of `odoo-admin`) |

## Everyday commands (run in `/opt/amarna/addons/deploy`)

    docker compose ps                 # state
    docker compose logs -f odoo       # logs
    docker compose restart odoo       # restart Odoo
    ./update.sh                       # git pull + update all modules + restart
    ./backup.sh                       # backup now

Containers restart by themselves (`restart: unless-stopped`) and Docker starts at boot.

## Rebuild from nothing

    git clone -b odoo20 https://github.com/RajaaSouadji/amarna_club_addons.git /opt/amarna/addons
    cd /opt/amarna/addons/deploy && ./setup.sh && docker compose up -d db
    docker compose run --rm -T odoo python3 /mnt/extra-addons/tools/bootstrap_db.py \
        --odoo-bin /usr/bin/odoo --config /etc/odoo/odoo.conf --db hasnaoui_amarna
    docker compose up -d
    python3 ../tools/seed_demo.py --url http://127.0.0.1:8069 --db hasnaoui_amarna --login admin --password admin   # sample data, optional

## Restore a backup

    docker compose exec -T db dropdb -U odoo hasnaoui_amarna
    docker compose exec -T db createdb -U odoo hasnaoui_amarna
    docker compose exec -T db pg_restore -U odoo -d hasnaoui_amarna < /opt/amarna/backups/<file>.dump
